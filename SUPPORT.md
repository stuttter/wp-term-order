# Support

For usage questions and help with released versions, use the
[WordPress.org support forum](https://wordpress.org/support/plugin/wp-term-order/).

For reproducible bugs and focused enhancements, use
[GitHub Issues](https://github.com/stuttter/wp-term-order/issues). Include the
WordPress and PHP versions, taxonomy type, selected database strategy, steps to
reproduce, expected behavior, and actual behavior.

Report suspected security vulnerabilities privately through
[GitHub Security Advisories](https://github.com/stuttter/wp-term-order/security/advisories/new).
